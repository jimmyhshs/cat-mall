# ROYAL PAW (로열포우) - 프리미엄 고양이 용품 쇼핑몰

다크블루(`#060F24`) & 로열블루(`#1D4ED8`) 컬러와 골드 포인트를 적용한 단일 파일(`index.html`) 반응형 고양이 쇼핑몰입니다.

## 폴더 구조
```text
├── index.html          # CSS · JS 인라인 통합 메인 쇼핑몰 페이지
├── .nojekyll           # GitHub Pages 정적 파일 호스팅 설정
├── README.md           # 배포 및 실행 안내
└── img/                # 12종의 히어로 배너 및 상품 스튜디오 이미지
    ├── hero-1.jpg ~ hero-4.jpg
    └── prod-tower.jpg, prod-salmon.jpg, prod-bed.jpg, prod-puree.jpg,
        prod-toy.jpg, prod-catpole.jpg, prod-crunch.jpg, prod-scratcher.jpg
```

## GitHub Pages 배포 방법
1. GitHub에 새 저장소(Repository)를 생성합니다.
2. 압축을 푼 폴더 안의 `index.html`, `.nojekyll`, `img` 폴더를 저장소 루트에 그대로 업로드합니다.
3. 저장소 상단 **Settings → Pages**에서 Branch를 `main` (폴더 `/ (root)`)으로 선택 후 **Save**를 누르면 즉시 배포됩니다.
